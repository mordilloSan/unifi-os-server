# Security

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
**Security → Report a vulnerability** on this repository.

## Scope

This repository covers what it adds on top of UniFi's image: the Dockerfile,
the entrypoint and helper scripts, the compose files and the workflows.

Vulnerabilities in UniFi OS Server itself, the Network application or any other
Ubiquiti software belong to Ubiquiti: https://hackerone.com/ui

## Supported versions

Only the latest release, the `latest` tag, receives fixes.
